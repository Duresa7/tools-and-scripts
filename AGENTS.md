## Commits and pull requests

Never credit an AI model, AI assistant, or AI vendor (for example Anthropic) as a co-author or contributor. Commit messages get no co-author trailer, and pull request descriptions get no AI attribution line.

## Agent skills

### Issue tracker

Issues and specs live in this repo's GitHub Issues and are managed with the `gh` CLI. See `docs/agents/issue-tracker.md`.

### Triage labels

The five default triage labels, each label string equal to its role name. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: one `CONTEXT.md` and `docs/adr/` at the repo root. See `docs/agents/domain.md`.

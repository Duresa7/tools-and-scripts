# Portability audit

This audit covers every tool folder, ai-configs, and the repository's own tooling as of 2026-09-25, at base commit `db9b85d`. Severities: **blocker** means it fails or does the wrong thing on another setup; **friction** means it works but needs a code edit or guesswork; **narrow** means a product assumption is narrower than necessary.

An independent review checked all 23 original blockers against the code: 3 were confirmed, 12 were downgraded, and 8 were rejected (see Rejected on review).

**Repeating patterns**

- Setup examples assume a fixed checkout location in `monitoring/prometheus-target-check`, `monitoring/grafana-dashboard-check`, `monitoring/dnf-updates`, `linux/wazuh-hash-list-refresh`, `automation/monitoring-exporters`, and `automation/ssh-key-rotation`, leaving readers to correct paths for their own clones.
- Service installation and cleanup assume particular exporter accounts, executable paths, or metrics directories in `monitoring/dnf-updates`, `monitoring/cloudflared-tunnel-health`, and `monitoring/teamspeak-voice-probe`; customized installations can fail or retain stale metrics.
- Interpreter assumptions limit otherwise supported setups: `monitoring/unifi-flow-collector`, `monitoring/unifi-flow-dashboards`, and `monitoring/cloudflared-tunnel-health` require Python 3.11 through unconditional imports, while credential examples in `monitoring/prometheus-target-check`, `monitoring/teamspeak-voice-probe`, and `automation/teamspeak-channel-migration` use a prompt unavailable in Windows PowerShell 5.1.
- File creation assumes hard-link support in `monitoring/unifi-flow-collector`, `monitoring/unifi-flow-dashboards`, and `automation/teamspeak-channel-migration`, preventing ordinary setup or export on some filesystems and mounted shares.
- Tests assume no personal configuration exists in `monitoring/cloudflared-tunnel-health`, `monitoring/minecraft-status-probe`, and `monitoring/unifi-flow-dashboards`; normal tool setup can change test results or trigger requests to configured endpoints.
- Fixed timing and volume assumptions constrain deployments in `monitoring/unifi-flow-collector` and `monitoring/unifi-flow-dashboards`, affecting backlog processing and detection sensitivity.

- **friction** `monitoring/cloudflared-tunnel-health/tests/test_tunnel_health.py:198-217` `monitoring/cloudflared-tunnel-health/tunnel_health.py:251-258`: The stdout test calls main without an explicit config, which automatically loads a real config.local.toml beside the tool. ### monitoring/discord-alert-relay
